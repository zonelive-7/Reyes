### 🚀 How to Run Locally

Since the project is still in development, you can clone it and run the current code using `cargo`:

```bash
# 1. Clone the repository
git clone "https://github.com/zonelive-7/Reyes"

# 2. Enter the directory
cd reyes

# 3. Run the project
cargo run
```
